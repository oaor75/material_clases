**Plugins Antigravity**

Aunque no existe una lista oficial y definitiva de los "10 mejores", en discusiones comunitarias de foros como Reddit (`r/google_antigravity`) y repositorios de GitHub, los usuarios destacan los siguientes 10 plugins, extensiones y servidores MCP (Model Context Protocol) para potenciar el IDE:

1. **Antigravity Cockpit:** Una extensión simple, confiable y con muchas funciones, utilizada principalmente para monitorear tu cuota de uso de los modelos LLM.  
2. **Graph-It-Live:** Permite visualizar las dependencias de los archivos de tu proyecto en forma de un gráfico interactivo.  
3. **Antigravity Jules Bridge Preview:** Un plugin recomendado para delegar (handoff) tareas de programación directamente a Jules, el agente de codificación autónomo de Google.  
4. **Antigravity Claude Proxy:** Un servidor proxy que expone una API compatible con Anthropic, lo que te permite usar modelos de Claude y Gemini a través de la interfaz de línea de comandos (CLI) de Claude Code.  
5. **Antigravity Quota (AGQ):** Una extensión muy ligera que rastrea y muestra el consumo de la cuota de tu modelo de IA directamente en la barra de estado del editor.  
6. **Antigravity-Manager:** Un administrador profesional de código abierto que permite cambiar entre múltiples cuentas con un solo clic, siendo muy útil para gestionar cuotas desde distintos inicios de sesión.  
7. **Toolkit for Antigravity:** Otra alternativa muy valorada por la comunidad para mantener a la vista los límites de uso de cuota, además de incluir varias utilidades adicionales.  
8. **Beads:** Una herramienta recomendada por los desarrolladores para realizar un seguimiento efectivo de las tareas pendientes (tracking tasks) dentro del entorno.  
9. **Supabase MCP:** Un servidor MCP oficial muy popular en la comunidad para automatizar la configuración de bases de datos, hacer consultas y desplegar *edge functions* directamente desde el chat del agente.  
10. **Antigravity Browser Control:** Catalogado por algunos usuarios como el "héroe anónimo", esta extensión de Chrome permite al agente de IA navegar, hacer clics, probar componentes y tomar capturas de pantalla automáticas para verificar visualmente que tu código funciona.

**Recomendación adicional de la comunidad:** Para maximizar el uso de los agentes autónomos, la comunidad también aconseja instalar **"Skills" (Habilidades agénticas)** desde el repositorio *Antigravity Awesome Skills*. Las más populares para empezar incluyen `@brainstorming` (para planificar), `@test-driven-development` (para desarrollo guiado por pruebas) y `@security-auditor` (para revisiones de seguridad). Asimismo, puedes integrar otros servidores MCP muy populares como **GitHub, Vercel, Cloudflare, AWS o Neon** para interactuar con servicios en la nube sin salir del IDE
