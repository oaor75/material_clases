// 1. Tomamos la respuesta del Basic LLM Chain
const aiOutput = $input.first().json;

// La respuesta puede venir en diferentes campos
let rawContent = aiOutput.text || aiOutput.content || aiOutput.message || aiOutput.response || aiOutput.output || JSON.stringify(aiOutput);

// Limpiamos si la IA puso ```json o ```
rawContent = rawContent.toString().replace(/```json\s*/gi, '').replace(/```\s*/gi, '').trim();

// 2. Convertimos a objeto JSON
let parsedData = {};
try {
  parsedData = JSON.parse(rawContent);
} catch (e) {
  const jsonMatch = rawContent.match(/\{[\s\S]*?\}/);
  if (jsonMatch) {
    try {
      parsedData = JSON.parse(jsonMatch[0]);
    } catch (e2) {
      parsedData = {};
    }
  }
}

// 3. Recuperamos datos del Google Drive Trigger (para la URL de la imagen)
const driveData = $('Google Drive Trigger').first().json;
const imageUrl = driveData.webViewLink || driveData.webContentLink || driveData.thumbnailLink || driveData.photoLink || '';

// 4. Recuperamos la imagen (binary) del nodo Download file
// Esto es CLAVE: si no guardamos la imagen aquí, se pierde antes de llegar a Facebook
const downloadedFile = $('Download file').first().binary;
const imageBinary = downloadedFile ? downloadedFile.data : null;

// 5. Devolvemos todo empaquetado: texto + imagen
return [{
  json: {
    mensaje: parsedData.mensaje || '',
    descripcion: parsedData.Descripcion || parsedData.descripcion || '',
    palabras_claves: parsedData.Palabras_claves || parsedData.palabras_claves || '',
    hashtags: parsedData.Hashtags || parsedData.hashtags || '',
    url_imagen: imageUrl,
    descripcion_imagen: parsedData.descripcion_imagen || ''
  },
  binary: imageBinary ? { data: imageBinary } : undefined
}];

TU MISIÓN:
Crear contenido optimizado para redes sociales (Facebook e Instagram) que:
1. Capture la atención en los primeros 3 segundos
2. Genere engagement (likes, comentarios, shares)
3. Mantenga la coherencia con la identidad de marca
4. Respete y acredite al fotógrafo original

REQUISITOS DEL CONTENIDO:

📝 MENSAJE PRINCIPAL:
- Longitud: 100-150 caracteres (óptimo para engagement)
- Tono: Inspiracional, profesional pero cercano
- Estilo: Conversacional, evita ser corporativo o robótico
- Gancho: Primera línea debe captar atención inmediatamente
- Call-to-action sutil: Invita a reflexionar o interactuar
- NO incluyas el crédito del fotógrafo aquí (se agregará después automáticamente)

🎨 ENFOQUE CREATIVO:
- Conecta emocionalmente con la audiencia
- Usa storytelling cuando sea apropiado
- Relaciona la imagen con experiencias universales
- Genera curiosidad o asombro
- Evita clichés obvios ("la belleza de la naturaleza", "momentos perfectos")

#️⃣ HASHTAGS:
- Cantidad: Exactamente 3-5 hashtags
- Mezcla: 2 populares + 2 específicos + 1 de nicho
- Relevancia: Relacionados directamente con el contenido visual
- Sin hashtags genéricos como #photo #pic #image
- Formato: Separados por espacios, al final del mensaje

🎯 VARIEDAD DE CONTENIDO:
Para evitar repetición, alterna entre estos estilos:
1. Pregunta reflexiva
2. Historia corta
3. Dato interesante/curioso
4. Cita inspiracional adaptada
5. Observación poética
6. Perspectiva única sobre lo cotidiano

🔍 OPTIMIZACIÓN SEO:
- Incluye palabras clave relevantes naturalmente
- Menciona elementos visibles en la foto
- Usa lenguaje que la gente buscaría

⚠️ PROHIBIDO:
- Emojis en exceso (máximo 2)
- Frases hechas o clichés
- Lenguaje comercial o de venta
- Mencionar marcas sin contexto
- Contenido que parezca generado por IA
- Repetir estructuras de mensajes anteriores

Responde ÚNICAMENTE con el mensaje final, sin:
